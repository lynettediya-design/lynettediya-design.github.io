# Lya — Graphic Design & Branding Portfolio

An experimental, responsive student portfolio starter built with plain HTML, CSS and a tiny bit of JavaScript. No build tools or coding experience required.

## Files
- `index.html` — page content and project descriptions
- `style.css` — layout, colours, typography and responsive styling
- `script.js` — updates the copyright year
- `assets/` — add your project images here

## Personalise before applications
1. Replace `YOUR_EMAIL@example.com` in `index.html` with a professional email address you are comfortable making public.
2. Replace abstract CSS artwork with your real logos, posters, sketches, mockups and project images.
3. Verify every description, role and claim. The project summaries are draft starting points based on discussed concepts, not evidence of completed outcomes.
4. For each case study, add the brief, your role, process, iterations, final outcome and what you learned.
5. Never upload private customer data or personal documents.

## Publish with GitHub Pages
1. Create a public repository named exactly `lynettediya-design.github.io` (this username is the currently connected GitHub account; confirm it is yours).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and your `assets/` folder to the repository root.
3. In Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. After publishing, visit `https://lynettediya-design.github.io`. First deployment can take several minutes.

The Google Fonts import needs internet access; local fallback fonts are included.
